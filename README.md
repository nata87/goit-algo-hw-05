#  Домашнє завдання №5: Алгоритми пошуку

## 📂 Структура

- `task1.py` — реалізація хеш-таблиці з методом `delete`
- `task2.py` — реалізація двійкового пошуку з підрахунком ітерацій і знаходженням верхньої межі
- `task3.py` — порівняння алгоритмів пошуку підрядка (БМ, КМП, РК)
- `task3_result.png` — Висновки щодо аналізу порівняння алгоритмів пошуку підрядка 
- `article1.txt`, `article2.txt` — текстові файли для аналізу у завданні 3

## 📋 Завдання

Реалізовано метод `delete` у класі `HashTable`. Він дозволяє видалити пару `ключ-значення`.

### Запуск

```bash
python task1.py
```

- Верхню межу (найменший елемент, більший або рівний заданому)

### Запуск

```bash
python task2.py
```
